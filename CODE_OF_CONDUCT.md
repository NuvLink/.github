# Código de Conduta

## Nosso compromisso

Mantemos um ambiente de trabalho respeitoso e profissional em todos os repositórios, issues, pull requests e discussões da NuvLink — internamente e com clientes/colaboradores externos.

## Esperado

- Comunicação respeitosa e objetiva.
- Feedback construtivo em code review.
- Respeito à confidencialidade de dados e código de clientes.

## Não tolerado

- Assédio, discriminação ou linguagem ofensiva.
- Compartilhamento não autorizado de dados de clientes ou credenciais.

## Aplicação

Violações podem ser reportadas para `contato@nuvlink.io` (ajustar para o e-mail real) e serão avaliadas pelos responsáveis pela organização.
