# .github

Configurações e padrões padrão da organização NuvLink:

- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `PULL_REQUEST_TEMPLATE.md` e `ISSUE_TEMPLATE/` são aplicados automaticamente a qualquer repositório da org que não tenha seus próprios.
- `NAMING.md` — convenção de nomes de repositórios.
- `workflow-templates/` — templates de GitHub Actions disponíveis ao criar um novo repositório (aba "Actions" → "New workflow").

Para adicionar a página de perfil público da organização (github.com/nuvlink), crie `profile/README.md` neste mesmo repositório.
