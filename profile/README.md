## O que fazemos

- **Automação de processos** — eliminamos tarefas manuais e repetitivas entre planilhas, sistemas e times.
- **Integração de sistemas** — conectamos ERPs, CRMs, APIs e ferramentas que hoje não conversam entre si.
- **Sistemas sob medida** — quando a automação não basta, construímos o sistema que falta.

## Como trabalhamos

Cada projeto de cliente é um repositório privado, com CI, revisão de código e boas práticas de segurança desde o primeiro commit — veja nossos [templates públicos](#projetos) pra ter uma ideia do padrão.
